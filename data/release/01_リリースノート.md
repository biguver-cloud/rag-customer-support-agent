## release-001|SampleDesk Version 3.2.0のリリース内容

**検索本文**
SampleDesk Version 3.2.0は、2026年5月にリリースされました。新機能として、AIサポート機能の精度向上(回答候補の関連度スコア表示。スコアが高いほど関連性が高い)、一括対応機能(複数の問い合わせを選択して一括でステータス変更・担当者アサインが可能)、Webhook連携(問い合わせの新規受信・ステータス変更時に外部サービスへ通知を送信でき、SlackやMicrosoft Teamsとの連携に活用可能)が追加されました。改善点として、ダッシュボードの表示速度を平均40%改善し、CSVエクスポート時のファイルサイズ上限を50MBから200MBに拡大し、モバイルブラウザでの表示レイアウトを最適化しました。バグ修正として、特定条件下でメール通知が二重送信される不具合、Safari最新版でファイル添付ができない不具合を修正しました。

**key_facts**
- バージョン: 3.2.0
- リリース時期: 2026年5月
- 新機能1: AIサポート機能の精度向上(回答候補の関連度スコア表示)
- 新機能2: 一括対応機能(複数問い合わせの一括ステータス変更・担当者アサイン)
- 新機能3: Webhook連携(Slack、Microsoft Teams等と連携可能)
- 改善1: ダッシュボード表示速度を平均40%改善
- 改善2: CSVエクスポートのファイルサイズ上限を50MBから200MBに拡大
- 改善3: モバイルブラウザの表示レイアウト最適化
- バグ修正1: メール通知の二重送信不具合を修正
- バグ修正2: Safari最新版でのファイル添付不具合を修正

**related_terms**: Version 3.2.0, リリースノート, AIサポート機能, 一括対応機能, Webhook連携

## release-002|SampleDesk Version 3.1.0のリリース内容

**検索本文**
SampleDesk Version 3.1.0は、2026年3月にリリースされました。新機能として、カスタムステータス機能(「未対応」「対応中」「完了」に加えて、独自のステータスを最大5つ追加可能)、対応テンプレートの変数機能(テンプレート内に{{顧客名}}などの変数を使用でき、送信時に自動的に置換される)、二段階認証の強制設定(管理者が全ユーザーへの二段階認証を必須にできる)が追加されました。改善点として、検索機能に全文検索(問い合わせ本文検索)を追加し、レポートに「平均対応時間」の指標を追加し、パスワードポリシーの設定画面を追加しました。

**key_facts**
- バージョン: 3.1.0
- リリース時期: 2026年3月
- 新機能1: カスタムステータス機能(独自ステータスを最大5つまで追加可能)
- 新機能2: 対応テンプレートの変数機能({{顧客名}}等、送信時に自動置換)
- 新機能3: 二段階認証の強制設定(管理者が全ユーザーに必須化可能)
- 改善1: 全文検索(問い合わせ本文検索)を追加
- 改善2: レポートに「平均対応時間」指標を追加
- 改善3: パスワードポリシーの設定画面を追加

**related_terms**: Version 3.1.0, リリースノート, カスタムステータス, 二段階認証, 全文検索

## release-003|SampleDesk Version 3.0.0のリリース内容

**検索本文**
SampleDesk Version 3.0.0は、2026年1月にリリースされました。新機能として、AIサポート機能を正式リリースし、問い合わせ内容に基づいて回答候補を提示するようになりました。また、キーワード検索とAIの意味検索を組み合わせたハイブリッド検索に対応しました。監査ログのCSVエクスポート機能も追加され、監査ログ出力オプション(月額2,000円、ビジネスプラン以上が対象)を追加することで、操作ログのエクスポートが可能になりました。このオプション料金は、基本の料金プラン(スタータープラン・チームプラン・ビジネスプラン)とは別に発生する追加費用です。変更点として、旧バージョン(V2系)のAPIは2026年7月をもって終了することになりました。V3 APIへの移行が必要です。また、スタータープランのユーザー数上限を2名から3名に変更しました。

**key_facts**
- バージョン: 3.0.0
- リリース時期: 2026年1月
- 新機能1: AIサポート機能の正式リリース(問い合わせ内容に基づく回答候補の提示)
- 新機能2: ハイブリッド検索対応(キーワード検索+AIの意味検索)
- 新機能3: 監査ログのCSVエクスポート機能(監査ログ出力オプション: 月額2,000円、ビジネスプラン以上が対象。基本料金プランとは別の追加費用)
- 変更1: V2系APIの終了時期: 2026年7月(V3 APIへの移行が必要)
- 変更2: スタータープランのユーザー数上限を2名から3名に変更(現行の上限3名は company カテゴリーの corp-006 と一致)

**related_terms**: Version 3.0.0, リリースノート, AIサポート機能, ハイブリッド検索, 監査ログ, V2 API終了

## release-004|SampleDesk Version 2.9.0のリリース内容

**検索本文**
SampleDesk Version 2.9.0は、2025年11月にリリースされました。新機能として、問い合わせのタグ機能(問い合わせに複数のタグを付けて分類・検索可能)、SLA設定機能(対応期限を設定し、期限超過時にアラートを送信)が追加されました。改善点として、添付ファイルの上限を5MBから10MBに拡大し、FAQのカテゴリ階層を3階層まで対応しました。

**key_facts**
- バージョン: 2.9.0
- リリース時期: 2025年11月
- 新機能1: 問い合わせのタグ機能(複数タグでの分類・検索)
- 新機能2: SLA設定機能(対応期限のアラート通知)
- 改善1: 添付ファイルの上限を5MBから10MBに拡大
- 改善2: FAQのカテゴリ階層を3階層まで対応

**related_terms**: Version 2.9.0, リリースノート, タグ機能, SLA設定, 添付ファイル上限
