## guide-001|Webhook連携機能の使い方

**検索本文**
Webhook連携を使うと、SampleDeskで問い合わせが届いたときや状態が変わったときに、SlackやMicrosoft Teams等の外部サービスに自動で通知を送ることができます。設定手順は、管理画面の「連携設定」から「Webhook」を開き、「新規Webhookを追加」をクリックし、送信先URL(Slackの場合はIncoming Webhook URL)を入力し、トリガー(新規問い合わせ受信、ステータス変更、担当者アサイン等)を選択し、「テスト送信」で動作確認をした後、「保存」で設定完了です。Slack連携の例では、問い合わせが届いたときに指定チャンネルへ「新しい問い合わせが届きました: [件名]」という通知が送られ、ステータスが「完了」になったときに通知する設定も可能です。

**key_facts**
- 機能概要: 問い合わせの新規受信・状態変更時に外部サービス(Slack、Microsoft Teams等)へ自動通知
- 設定手順: 連携設定→Webhook→新規Webhook追加→送信先URL入力→トリガー選択→テスト送信→保存
- 選択可能なトリガー: 新規問い合わせ受信、ステータス変更、担当者アサイン
- 提供開始: Version 3.2.0(2026年5月、release-001参照)

**related_terms**: Webhook連携, 使い方, Slack連携, Microsoft Teams, 通知設定

## guide-002|カスタムステータス機能の使い方

**検索本文**
デフォルトの「未対応」「対応中」「完了」に加えて、自社の業務フローに合わせたステータスを、最大5つまで追加できます。設定手順は、管理画面の「ステータス設定」を開き、「カスタムステータスを追加」をクリックし、ステータス名と色を設定し(例:「承認待ち」を黄色、「エスカレーション中」を赤に設定)、ステータスの順序をドラッグで並べ替え、「保存」で完了です。活用例として、「未対応」→「対応中」→「承認待ち」→「完了」という4段階フローを設定することで、上長確認が必要な問い合わせを管理しやすくなります。

**key_facts**
- 機能概要: デフォルト3ステータスに加え、独自ステータスを追加できる
- 追加できる上限: 最大5つまで(release-002参照)
- 設定手順: ステータス設定→カスタムステータス追加→名前と色の設定→順序の並べ替え→保存
- 設定できる項目: ステータス名、色、表示順序
- 提供開始: Version 3.1.0(2026年3月、release-002参照)

**related_terms**: カスタムステータス, 使い方, ステータス設定, 業務フロー

## guide-003|対応テンプレートの変数機能

**検索本文**
テンプレートに変数を挿入することで、顧客ごとにパーソナライズされた回答を素早く作成できます。使用可能な変数は、問い合わせ送信者の名前を表す{{顧客名}}、送信者の会社名を表す{{会社名}}、問い合わせの管理番号を表す{{問い合わせ番号}}、受付日時を表す{{受付日時}}、対応担当者の名前を表す{{担当者名}}の5種類です。使用例として、「{{顧客名}}様、この度はお問い合わせいただきありがとうございます。担当の{{担当者名}}がご対応いたします。お問い合わせ番号は{{問い合わせ番号}}です。」のような文面を作成できます。

**key_facts**
- 機能概要: テンプレート内に変数を挿入し、送信時に自動置換してパーソナライズする
- 使用可能な変数: {{顧客名}}、{{会社名}}、{{問い合わせ番号}}、{{受付日時}}、{{担当者名}}(全5種類)
- 提供開始: Version 3.1.0(2026年3月、release-002参照)

**related_terms**: テンプレート変数, 使い方, パーソナライズ, 変数一覧

## guide-004|AIサポート機能の活用方法

**検索本文**
AIサポート機能は、問い合わせ内容に基づいて回答候補を自動提示します。担当者はAIが提案した回答を参考にしながら、最終的な返答内容を判断・編集して送信します。Version 3.2.0以降は、回答候補ごとに関連度スコアが表示されるようになっており、スコアが高いほど関連性の高い回答候補であることを示します。精度を上げるポイントとして、FAQの質と量を充実させること、具体的な質問と回答のペアを登録すること、定期的にFAQを見直し古くなった情報を更新すること、対応履歴を蓄積することが挙げられます。

**key_facts**
- 機能概要: 問い合わせ内容に基づき、AIが回答候補を自動提示する
- 関連度スコア表示: Version 3.2.0以降、回答候補ごとにスコアを表示(スコアが高いほど関連性が高い。release-001参照)
- 精度向上のポイント1: FAQの質と量を充実させる
- 精度向上のポイント2: 具体的な質問と回答のペアを登録する
- 精度向上のポイント3: 定期的にFAQを見直し、古い情報を更新する
- 精度向上のポイント4: 対応履歴の蓄積量を増やす
- 提供開始: Version 3.0.0(2026年1月、release-003参照)、関連度スコア表示はVersion 3.2.0で追加

**related_terms**: AIサポート機能, 活用方法, 関連度スコア, FAQ精度向上

## guide-005|SLA設定機能の使い方

**検索本文**
SLA(Service Level Agreement)設定を使うと、問い合わせへの対応期限を管理できます。設定手順は、管理画面の「SLA設定」を開き、カテゴリまたは優先度ごとに対応期限を設定し(例:緊急は4時間、通常は24時間)、期限超過前の通知タイミングを設定し(例:期限1時間前にアラート)、アラートの送信先担当者を設定します。SLAが設定されると、問い合わせ一覧に対応期限と残り時間が表示され、期限が近づくと色が黄色から赤に変わり、視覚的に優先度を把握できます。

**key_facts**
- 機能概要: 問い合わせへの対応期限(SLA)を設定・管理できる
- 設定手順: SLA設定→カテゴリ/優先度ごとに期限設定→通知タイミング設定→送信先担当者設定
- 設定例: 緊急=4時間、通常=24時間、期限1時間前にアラート
- 表示: 問い合わせ一覧に対応期限と残り時間を表示、期限接近で黄→赤に変化
- 提供開始: Version 2.9.0(2025年11月、release-004参照)

**related_terms**: SLA設定, 使い方, 対応期限, アラート通知
